# Proposal Image Case Studies

Each case study is a candidate-specific application of the reusable [proposal image rubric](../proposal-image-rubric.v1.md). It must keep the generic framework separate from findings that apply only to one proposed emoji.

## Required case-study contents

- Candidate name and submission-package semver version.
- The four exact input filenames and generated deterministic-analysis JSON.
- Candidate-specific likely confusables, selected before any optional blinded test.
- The invariant cue inventory: one primary silhouette cue and no more than two secondary cues.
- Optional blinded recognition and confusability results, or an explicit statement that testing has not been run and is not claimed.
- A decision: retain, revise, or replace the artwork.
