# Microsoft Unicode routing contacts for Medical Emoji

This is the accessible text companion to the one-page Microsoft-only contact map:

https://github.com/ShuhanCS/medicalemoji/blob/codex/eligible-2026-slate/output/pdf/2026-07-13-who-can-help-with-medical-emoji-review.pdf

The public roles below were checked against official Unicode sources on July 13, 2026. Unicode does not
publish Microsoft's internal delegate assignments or a complete current roster for the Emoji Standard &
Research Working Group, so those roles should be confirmed inside Microsoft.

## Recommended start

Start with **Peter Constable** for the technical and standards path. He is a Microsoft employee, Unicode
Technical Vice President, chair of the Unicode Technical Committee, and chair of the UTC Release Management
Working Group. The latest published UTC minutes also list him as representing Microsoft.

Use **Vishal Chowdhary** for executive routing. He is Vice President of Science at Microsoft and a Unicode
Board director for the 2026 term. The Board governs the organization; it does not select emoji or decide
technical outcomes.

The practical route is:

`David Rhew -> Peter Constable and Vishal Chowdhary -> confirmed Microsoft UTC and ESR participants -> UTC or ESR process`
