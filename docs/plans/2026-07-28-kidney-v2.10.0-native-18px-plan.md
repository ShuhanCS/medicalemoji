# Kidney v2.10.0 Native 18-Pixel Artwork Plan

Date: 2026-07-28

Audience: Unicode emoji proposal reviewers evaluating recognizability and technical compliance.

## Objective

Replace the malformed 18x18 examples in the Kidney proposal with purpose-built native pixel art that remains
recognizable at the required display size. Preserve the accepted paired-kidney concept, 72x72 artwork, submitter
order, proposal evidence, citations, and all prior immutable packets.

## Scope

- Create `submissions/v2.10.0` as an immutable successor to `v2.9.0`.
- Draw the color and black-and-white 18x18 examples directly on an 18-pixel grid; do not downsample another asset.
- Retain a one-pixel transparent margin and a shared paired-kidney silhouette.
- Preserve the 72x72 submission images byte-for-byte apart from their versioned filenames.
- Update the proposal's visual description so it accurately describes the native 18x18 artwork.
- Rebuild the PDF and validation records without changing the form, Drive file, or any email.

## 18x18 Design Specification

- Two large, inward-facing kidney bodies with visible medial notches.
- A dark outline and restrained maroon fill in color.
- A short red/blue central vessel cue and two short tan ureter cues in color, echoing the 72x72 example.
- The same outer contour in black and white, with white interiors, black outlines, a central connector, and short
  ureter cues.
- Fully transparent pixels outside the artwork, fully opaque pixels inside it, and no antialiasing or fractional
  alpha at native size.
- Native SVG sources use `viewBox="0 0 18 18"` and `shape-rendering="crispEdges"` so each raster pixel is
  reproducible and auditable.
