# Kidney v2.4.0 Compatibility Revision Plan

## Audience and outcome

This is an external Unicode emoji proposal for Emoji Standard and Research Working Group reviewers.
The revision will make the Kidney proposal directly answer Unicode's current evidence, compatibility,
and existing-user-experience priorities without overstating unsupported platform behavior.

## Starting point

- Preserve the paired-kidney artwork, exact ten-person submitter order, affiliations, and David Rhew's
  title from `submissions/v2.3.2/`.
- Restore the verified CLDR evidence previously present in `v2.2.2`.
- Preserve the stronger sourced use cases and Beans-ambiguity discussion from `v2.3.2`.

## Argument changes

1. Under **Breaks new ground**, document that the current English CLDR annotations associate
   `kidney` only with U+1FAD8 BEANS, whose short name is `beans`.
2. Answer the annotation-only objection directly: removing the inaccurate keyword would stop the
   misleading association but would still leave users with no kidney-organ character to find.
3. Replace **Compatibility: Not applicable** with a narrowly sourced explanation of CLDR's documented
   emoji-search model and the present concept-to-pictograph mismatch.
4. Under **Already representable**, distinguish searchability from representation and explain why
   Beans and short sequences remain ambiguous.
5. Cite Unicode's stated Emoji 19.0 priorities and the 2025 Monarch Butterfly compatibility precedent
   as process context, not as an entitlement or faulty comparison.

## Evidence boundaries

- Cite official Unicode and CLDR sources for annotations, search-keyword behavior, proposal priorities,
  and UTC minutes.
- Do not claim that a named Microsoft product currently returns Beans for `kidney` without captured,
  reproducible evidence from that product.
- Record current platform screenshots as a remaining strengthening opportunity rather than inventing
  compatibility evidence.

## Version decision

Create immutable proposal packet `v2.4.0`. This is a MINOR packet change because the inclusion case and
Compatibility factor change substantively. Bump the repository version from `0.27.2` to `0.28.0`.

## Release gates

- Proposal and PDF contain the exact approved submitter list and paired artwork.
- Section G no longer says Compatibility is not applicable.
- Proposal expressly explains why removing the Beans keyword alone does not supply a kidney-organ
  representation.
- CLDR and Unicode process claims link to primary official sources.
- All retained images have synchronized `v2.4.0` filenames and required dimensions.
- Extracted PDF text contains the new argument, and every rendered page passes visual inspection.
- Packet remains marked `NOT FILED - REVIEW REQUIRED`; no email or submission is sent.
