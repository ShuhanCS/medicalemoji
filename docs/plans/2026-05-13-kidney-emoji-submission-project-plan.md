# Kidney Emoji Submission Project Plan - 2026-05-13

## Goal

Prepare the Medical Emoji repo for a serious 2026 kidney emoji submission effort using current Unicode rules and current factual evidence.

## Scope

- Audit the active Unicode emoji intake timeline and submission requirements.
- Identify the current kidney/kidneys proposal status and resubmission risk.
- Build a source-backed fact base that distinguishes current public health facts from older campaign claims.
- Create a submission workspace with a draft proposal outline and evidence-capture checklist.

## Source Priority

1. Unicode official pages and L2/ESR documents.
2. WHO, CDC, and peer-reviewed epidemiology sources for disease burden.
3. Existing Medical Emoji coalition letters as support material, not as primary frequency evidence.

## Key Decision

Do not submit until we verify whether the four-year re-review bar runs from the `KIDNEYS` submission date, the decline decision date, or the annual status-publication date. The public Unicode status CSV lists `KIDNEYS` as declined with date submitted `2022-07-19`, but it does not expose the decline date.
