                   1. Multiple usages - As well as being useful in everyday conversation
                        without subtext, the Peas emoji would be useful in a number of
                        circumstances that don't directly reference peas. For example, `peas
                        in a pod' is a widely used turn of phrase, as well as being relevant for
                        any puns ending in `-py' (e.g. Hap-pea Birthday, Hap-pea Mother's
                        Day). Furthermore, colourful emojis are used widely to depict
                        something being a certain colour (e.g. a group of green emojis might
                        be used to caption an image of something very green.) It can also be
                        used to denote similar vegetables, e.g. mangetout.

                   2. Use in sequences � N/A

                   3. Breaking new ground � The `Peas' emoji would not just been another
                        variant of an existing emoji. It would tread new ground in terms of its
                        category and would fit well within the range of vegetables currently in
                        use.

    C. Image distinctiveness � The proposed emoji graphic for `peas' is not just
         representing a single pea but enhancing its visual description by showing three
         large peas within a pod. There are no other emoji that currently represent this.

    D. Completeness � n/a

6. Selection factors -- Exclusion

    E. Petitions or "frequent requests" - As per the Emoji Requests webpage
         (https://unicode.org/emoji/emoji-requests.html) there have been no previous
         requests for a `peas' emoji.
    F. Overly specific: As there are other food-vegetables available as emojis, the `peas'
         emoji is a universally useful graphic that would fit alongside others in the same
         category.

    G. Open-ended. This is an individual emoji and currently not represented within its
         food-vegetable category.

    H. Already representable. There are no emoji that could currently be used in place
         of `peas'.
