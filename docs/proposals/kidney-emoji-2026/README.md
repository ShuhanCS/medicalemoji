# Kidney Emoji 2026 Submission Project

This folder is the working project for a renewed kidney emoji submission.

## Current Practical Posture

The proposal is worth preparing, but should not be filed until eligibility is verified. Unicode's public status sheet lists two declined kidney-related entries:

| Emoji | Status | Date Submitted |
| --- | --- | --- |
| Kidney | Declined | 2019-12-17 |
| KIDNEYS | Declined | 2022-07-19 |

Current Unicode guidance says emoji declined within the last four years are not eligible for re-review. The public status sheet gives the submission date, not the decline decision date. That makes the 2026 timing question real, not theoretical.

## Folder Contents

- `unicode-timeline-and-guidelines.md` - current Unicode process, timeline, and current-format requirements.
- `fact-base.md` - real, citable kidney disease facts with source URLs.
- `evidence-capture-checklist.md` - exact frequency-evidence screenshots to capture before filing.
- `proposal-draft-outline.md` - current-format draft scaffold for the proposal PDF.
- `decline-date-submission-update.md` - current decline-date finding, submission URLs, 2026 template requirements, and detailed coordination email draft.

## Recommended Submission Strategy

1. Coordinate with the Turkish Society of Nephrology and ISN before any filing.
2. Ask Unicode/ESR to confirm the re-review eligibility date for `KIDNEYS`.
3. Treat society letters and petitions as coalition material only; do not rely on them as required evidence.
4. Build the case around objective expected usage, broad meaning, visual distinctiveness, and current epidemiology.
5. Submit one clean, current-format PDF through the official Unicode form only after eligibility and image rights are solved.
