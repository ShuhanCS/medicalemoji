## Current Submission Requirements

Official guidelines:
https://www.unicode.org/emoji/proposals.html

FAQ:
https://www.unicode.org/faq/emoji_submission.html

Agreement/license:
https://www.unicode.org/emoji/emoji-proposal-agreement.pdf

Submission form:
https://forms.gle/6KSiYHrUdBkTMNaB8

Required process:

- Confirm the emoji is not already approved.
- Check the existing proposal status list before drafting.
- Confirm no same-concept proposal is `Prioritization Pending` or `Under Consideration`.
- Confirm the declined-proposal re-review bar does not apply.
- Prepare a public PDF proposal document.
- Submit through the official Google Form only; email, fax, and hard copies are not accepted.
- Include the mandatory agreement/license.
- Use a publicly accessible PDF link.

Required proposal top matter:

- Title: `Proposal for Emoji: <name>`.
- Submitter names, separated by semicolons when there are multiple authors.
- One main point of contact.
- Date, updated on revisions.
- Identification keywords.
- Proposed emoji category.
- Color and black-and-white example images at 18x18 and 72x72 pixels.
- Image license/IP statement.

Image requirements:

- Color image required.
- Black-and-white image required.
- Both 18x18 and 72x72 sizes required.
- Grayscale is not acceptable.
- Submitter must own all image rights, have assignment/work-for-hire rights, or cite a public-domain/open-source source URL with the license visible.
- This applies even if the images were created with AI tools.

Required frequency evidence:

- Google Search screenshot with result count.
- Google Video Search screenshot with result count.
- Google Trends Web Search screenshot.
- Google Trends Image Search screenshot.
- Google Books Ngram Viewer screenshot.
- Trends and Ngram evidence must include `elephant` as a comparator.
- Use the widest possible date range.
- Use private/incognito browsing where possible.
- Use clarifying terms when the target term is ambiguous.
- Use additional non-English language terms if usage is strong in a broad region but low in English.

Evidence that does not count:

- Petitions.
- Social media hashtags.
- Anecdotal claims.
- Examples of people asking for the emoji.
- Cause-based arguments by themselves.

Selection factors that must be addressed:

- Multiple meanings.
- Use in sequences.
- Breaks new ground.
- Distinctiveness and recognizability at emoji size.
- High usage level.
- Completeness, only if it is a closed/non-open-ended set.
- Compatibility with popular existing systems, only if supported with evidence.

Exclusion factors that must be addressed:

- Already representable by existing emoji or sequences.
- Overly specific.
- Open-ended, meaning one of many with no special reason to favor it.
- Transient or fad-based.
- Faulty comparison to existing emoji.

Automatically declined categories:

- Logos, brands, third-party IP, UI icons, signage.
- Specific people.
- Specific buildings, landmarks, or locations.
- Deities.
- Region flags without ISO 3166 codes.
- Images lacking required rights or license.
- Requests for exact images.
- Emoji containing text.
- Directional variations.

## Implications For Kidney

The kidney case should not be framed mainly as "this cause matters" or "we have many supporters." Those points help coalition-building but do not satisfy the current review criteria.

The strongest path is:

- Prove high expected usage with reproducible search and trend evidence.
- Show that the kidney is visually iconic at 18x18 and distinct from beans, organs, and existing anatomical emoji.
- Argue broad expressive use: kidney health, kidney disease, transplant, donation, dialysis, anatomy, kidney stones, urinalysis, filtration, and public health.
- Address the open-ended anatomy risk directly: kidney is not merely one organ in an endless list; it is a paired vital organ with major global disease burden, transplant/donation use, dialysis use, and public-health relevance.
