# Liver Emoji 2026 Submission Project

This folder is the working project for a renewed Liver emoji submission.

## Current Status

The proposal is worth preparing now, but should not be filed until eligibility is confirmed. Unicode's public status CSV lists two declined Liver rows:

| Emoji | Status | Public date submitted |
| --- | --- | --- |
| Liver | Declined | 2020-12-18 |
| Liver | Declined | 2022-07-30 |

Unicode guidance says declined emoji are not eligible for re-review within the last four years. If the four-year clock is counted from the public `Date Submitted` field, Liver becomes reeligible on 2026-07-30. That is only one day before the 2026 intake deadline of 2026-07-31, so the team should confirm the actual decline/notification date with Unicode or ESR before filing.
