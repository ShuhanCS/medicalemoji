# Stomach Emoji 2026 Submission Project

This folder is the working project for a renewed Stomach emoji submission.

## Current Status

The proposal is worth preparing now, but should not be filed until eligibility is confirmed. Unicode's public status CSV lists two declined Stomach rows:

| Emoji | Status | Public date submitted |
| --- | --- | --- |
| Stomach | Declined | 2020-10-27 |
| Stomach | Declined | 2022-07-28 |

Unicode guidance says declined emoji are not eligible for re-review within the last four years. If the four-year clock is counted from the public `Date Submitted` field, Stomach becomes reeligible on 2026-07-28. That is only three days before the 2026 intake deadline of 2026-07-31, so the team should confirm the actual decline/notification date with Unicode or ESR before filing.

Prepare the evidence and draft now, but do not submit until:
