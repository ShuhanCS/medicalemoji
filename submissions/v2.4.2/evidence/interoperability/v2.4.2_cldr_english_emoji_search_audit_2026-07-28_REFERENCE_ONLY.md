## Method

Parse every English `<annotation>` element. Split non-TTS annotation text on the pipe delimiter, normalize each
token to lowercase, and look for exact token matches. TTS short names are part of the same source but none of
the audited search terms matched a TTS value.

## Interpretation and limit

CLDR provides no exact English annotation route from the organ name or the core concepts `digestion`, `gut`,
or `abdomen` to an emoji. Related words are distributed across pregnancy-related people, faces, food, utensils,
and an anxiety expression. A Stomach code point would give CLDR a directly named semantic target and would let
existing characters participate in less ambiguous sequences.

This is evidence about the standard English annotation data. It does not claim that every operating-system,
messaging, or social application exposes CLDR search identically; products can extend or replace annotations.
