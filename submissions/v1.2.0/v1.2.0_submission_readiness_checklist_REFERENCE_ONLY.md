# Kidney Emoji v1.2.0 Submission Readiness Checklist

Packet version: `v1.2.0`

Status: planned submission packet checklist. This file is `REFERENCE_ONLY`; it is not part of the Unicode PDF.

Controlling rubric:
https://github.com/ShuhanCS/medicalemoji/blob/master/docs/proposals/emoji-proposal-approval-rubric.md

## Argument Review

- [x] Proposal leads with ordinary-language communication instead of disease advocacy.
- [x] Concrete sequence examples support anatomy education, body function, family updates, donation, transplant, and monitoring.
- [x] Substitute table explains specific failures of Bean, Droplet, medical-context emoji, and existing sequences.
- [x] Open-ended answer uses a limited evidence-based rule, not anatomy-taxonomy completion.
- [x] Support letters are labeled supplemental rather than expected-usage evidence.
- [ ] At least one non-medical reviewer can explain the case without prompting.
- [ ] At least one Unicode/process reviewer has assessed the final argument and format.

## Visual Review

- [x] Color and black-and-white 18x18 and 72x72 candidate images exist.
- [x] Candidate uses one large kidney silhouette, a medial hilum, and a short urinary-system cue.
- [x] Native-size visual review board is embedded in the proposal.
- [ ] Cold-recognition test includes at least 12 participants, including at least 8 non-medical reviewers.
- [ ] Color recognition reaches the target: at least 80% identify Kidney or urinary-system anatomy.
- [ ] Black-and-white recognition reaches the target: at least 65% identify Kidney or urinary-system anatomy.
- [ ] Fewer than 10% call either candidate Bean, Heart, Peach, or an unspecified red organ.

## Filing Controls

- [x] Eligibility is confirmed by project decision.
- [ ] Final submitter list and main point of contact are confirmed.
- [ ] Final image-rights warranty is approved by the authorized signatory.
- [ ] Frequency screenshots are refreshed, accepted, and inserted with reproducible URLs.
- [ ] Exported PDF preserves native-size images and evidence readability.
- [ ] Final PDF is public and accessible without login.
- [ ] Official Unicode form submission confirmation is archived after filing.
