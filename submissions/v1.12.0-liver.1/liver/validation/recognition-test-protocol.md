# Liver 18-Pixel Recognition Test

Status: **READY TO RUN - RESULTS NOT YET COLLECTED**

This is an internal Medical Emoji quality gate, not a Unicode requirement. Do not replace real responses with
AI labels or inferred computer-similarity results.

## Materials

- `recognition-card-color-18px.png`
- `recognition-card-bw-18px.png`
- `liver-comparison-board.png` for the forced-choice pass only

Show each recognition card at 100% browser zoom. The icon embedded in each card is exactly 18x18 pixels.

## Procedure

1. Recruit at least 12 people who were not told the target and did not review the artwork.
2. Randomize whether each participant sees color or black-and-white first.
3. Show the first card alone and ask, `What is this?`
4. Record the exact free-text answer before showing any choices.
5. Repeat with the second card.
6. Run a forced-choice pass using Liver, Anatomical Heart, Lungs, Brain, Cut of Meat, and Beans.
7. Pass only if at least 10 of 12 identify Liver or an accepted synonym in both free-text passes and no wrong
   answer dominates.
